导出格式说明

JSON v2 中 source.path 固定为空字符串，仅保留 width / height。图源路径在游戏项目 puzzle-configs.js 的 sourceImage 中配置。

合并 JSON（bundle） 勾选多个配置后导出为一个文件，共享顶层 source，configs[] 内每项为独立拼图配置。

PNG 切片 可选导出；若 JSON 不含 base64，游戏会从 sourceImage 按坐标实时切图。
