# 轻度提示气泡绘制规则

本文档归纳 **轻度提示气泡**（浅绿胶囊飘字）的视觉规格、动画与双端绘制逻辑，供项目迁移时按规则复现，不依赖原工程路径。

> **范围**：场景内瞬时反馈用的胶囊飘字（无尾巴）。  
> **不含**：带三角尾巴的引导泡、面板式短提示、可点击操作条、底部羊皮纸提示条、客人订单圆气泡。

---

## 1. 定位与选用

| 项 | 约定 |
|----|------|
| 用途 | 收款、上菜、操作成功/失败等瞬时文案反馈 |
| 形态 | 胶囊形圆角矩形，**无尾巴** |
| 交互 | 不响应点击，不挡触摸 |
| 音效 | 无 |
| 生命周期 | 弹出 → 驻留 → 淡出，合计约 **1.38s** |

### Canvas 与 DOM 如何选用

| 方式 | 适用 |
|------|------|
| **Canvas** | 高频提示（营业中收款、上菜等），避免反复创建/销毁 DOM |
| **DOM** | 低频反馈、需运行时覆写配色、或与 DOM 锚点混排 |

两端必须共用同一套 **配色、盒模型、锚点语义与动效关键帧**，观感一致。

---

## 2. 配色

### 默认态（浅绿）

| 属性 | 色值 |
|------|------|
| 背景 | `rgba(129, 199, 132, 0.78)` |
| 描边 | `rgba(255, 255, 255, 0.35)` |
| 文字 | `#FFFFFF` |
| 阴影色 | `rgba(0, 0, 0, 0.22)` |

### 警告态（浅黄）

| 属性 | 色值 |
|------|------|
| 背景 | `rgba(255, 224, 130, 0.82)` |
| 描边 | `rgba(255, 255, 255, 0.42)` |
| 文字 | `#FFFFFF` |
| 阴影色 | `rgba(120, 90, 20, 0.18)` |

警告态用于失败/不足等负向反馈；文字色与默认态相同。

---

## 3. 盒模型与文本

按 **border-box** 理解外框尺寸。

| 属性 | 数值 |
|------|------|
| 字号 | `12px` |
| 字重 | `700` |
| 行高 | `1.35` |
| 字体 | `'PingFang SC', 'Microsoft YaHei', 'Helvetica Neue', sans-serif` |
| 文字阴影 | 无 |
| 水平内边距 | `11px` |
| 垂直内边距 | `6px` |
| 外圆角 | `14px` |
| 描边宽度 | `1.2px` |
| 投影 | `0 3px 11px`（Y 偏移 3，模糊 11） |
| 换行 | 默认单行不换行 |

### 外框尺寸公式（Canvas / 自绘）

```
contentH     = 12 × 1.35
outerW       = 文字宽度 + 11×2 + 1.2×2
outerH       = contentH + 6×2 + 1.2×2
填充圆角     = max(0, 14 − 1.2)
描边圆角     = max(0, 14 − 1.2/2)
```

填充矩形相对外框内缩 `1.2px`，描边矩形内缩 `0.6px`，使自绘与 CSS `border` + `border-radius` 观感一致。

---

## 4. 锚点与定位

| 项 | 规则 |
|----|------|
| 锚点含义 | **气泡底边的水平中心** 落在目标点 |
| DOM 做法 | 元素 `left/top` 设为目标点；`transform: translate(-50%, -100%)` 完成底边居中 |
| Canvas 做法 | 气泡几何中心 `cx = x`，`cy = y − outerH/2 + bob`（`bob` 为动画纵向位移） |
| 下方显示 | 需要时把锚点下移约 `18px`，避免挡住上方图像 |
| 相机 | Canvas 绘制须落在相机变换之后，随场景缩放/平移 |

---

## 5. 动画

### 时长参数

| 阶段 | 时长 |
|------|------|
| 弹出（Pop） | **500ms** |
| 驻留（Hold） | **600ms** |
| 淡出（Out） | **280ms** |
| 上飘幅度 | **5px** |
| 合计 | **1380ms** |

补充约定：

- DOM 节点可在动画结束后再多留约 **50ms** 再移除，避免尾帧闪断。
- Canvas 条目寿命 **1.38s**，到期剔除。
- 建议同时存在上限约 **12** 条，超出丢弃最旧。

### 5.1 弹出（0 → 500ms）

缓动：`cubic-bezier(0.34, 1.56, 0.64, 1)`（带弹性 overshoot）。

以 Pop 进度 `u ∈ [0, 1]`、`rise = 5` 为关键帧（中间帧线性插值）：

| u | 透明度 | 缩放 | 纵向 bob |
|---|--------|------|----------|
| 0 | 0 | 0.5 | `+rise`（偏下） |
| 0.55 | 1 | 1.05 | `−rise`（上飘） |
| 0.72 | 1 | 0.96 | `+1` |
| 0.88 | 1 | 1.02 | 0 |
| 1 | 1 | 1 | 0 |

DOM：在 `translate(-50%, -100%)` 基线上叠加 bob 与 scale。  
Canvas：对关键帧做线性插值后得到 `{ opacity, scale, bob }`。

### 5.2 驻留（500 → 1100ms）

透明度 `1`，缩放 `1`，`bob = 0`，静止。

### 5.3 淡出（1100 → 1380ms）

缓动：`ease-in`。进度 `u` 从 0→1：

| 属性 | 起 | 终 |
|------|----|----|
| 透明度 | 1 | 0 |
| 缩放 | 1 | **0.68** |
| bob | 0 | 0 |

### 5.4 透明度合成

元素级透明度与半透明背景色相乘。Canvas 用绘制态全局透明度控制元素级淡入淡出；底色本身已含 alpha，二者叠加后与 DOM 观感一致。

## 6. Canvas 绘制流程

1. 文字水平居中、垂直居中对齐；字体同第 3 节。
2. 按年龄采样 `{ opacity, scale, bob }`；透明度 ≤ 0.01 跳过。
3. 测量文字宽度，按公式算 `outerW / outerH`。
4. 平移到气泡中心 → 缩放 → 设置全局透明度。
5. 开启投影 → 圆角矩形填充（内缩描边宽）→ 关闭投影 → 描边 → 在局部原点绘制文字。
6. 恢复绘制状态，处理下一条。

每条数据至少包含：文案、世界坐标、年龄、寿命、是否警告态。

## 7. DOM 样式参考

可直接作为迁移实现基线（色值已内联）：

```css
.float-tip {
    position: absolute;
    padding: 6px 11px;
    border-radius: 14px;
    background: rgba(129, 199, 132, 0.78);
    border: 1.2px solid rgba(255, 255, 255, 0.35);
    box-shadow: 0 3px 11px rgba(0, 0, 0, 0.22);
    font-weight: 700;
    font-size: 12px;
    line-height: 1.35;
    font-family: 'PingFang SC', 'Microsoft YaHei', 'Helvetica Neue', sans-serif;
    color: #FFFFFF;
    text-shadow: none;
    pointer-events: none;
    white-space: nowrap;
    transform: translate(-50%, -100%);
    opacity: 0;
    animation:
        floatTipPopIn 500ms cubic-bezier(0.34, 1.56, 0.64, 1) forwards,
        floatTipOut 280ms 1100ms ease-in forwards;
}

.float-tip.is-warn {
    background: rgba(255, 224, 130, 0.82);
    border-color: rgba(255, 255, 255, 0.42);
    box-shadow: 0 3px 11px rgba(120, 90, 20, 0.18);
}

@keyframes floatTipPopIn {
    0% {
        opacity: 0;
        transform: translate(-50%, calc(-100% + 5px)) scale(0.5);
    }
    55% {
        opacity: 1;
        transform: translate(-50%, calc(-100% - 5px)) scale(1.05);
    }
    72% {
        transform: translate(-50%, calc(-100% + 1px)) scale(0.96);
    }
    88% {
        transform: translate(-50%, -100%) scale(1.02);
    }
    100% {
        opacity: 1;
        transform: translate(-50%, -100%) scale(1);
    }
}

@keyframes floatTipOut {
    0% {
        opacity: 1;
        transform: translate(-50%, -100%) scale(1);
    }
    100% {
        opacity: 0;
        transform: translate(-50%, -100%) scale(0.68);
    }
}
```

建议挂在独立浮层上（不响应事件），层级高于场景、低于全屏面板。

## 8. 教学驻留变体（可选）

同源浅绿胶囊，用于步骤说明时需驻留到步骤结束：

| 差异 | 规则 |
|------|------|
| 存活 | 手动关闭，**不做**自动淡出 |
| 换行 | 允许换行，最大宽度约 `min(240px, 视口宽 − 24px)`，文字居中 |
| 定位 | 不用底边居中 transform，改为绝对定位并做边缘夹紧 |
| 入场 | 仅缩放 `0.5 → 1.05 → 1` + 淡入，**无**上下 bob |

配色仍用默认浅绿，勿改成深色引导泡样式。

---

## 9. 迁移检查清单

实现完成后自检：

1. 默认 / 警告两套配色与投影是否一致  
2. 字号、字重、行高、padding、圆角、描边宽是否一致  
3. 锚点是否为「底边水平中心」  
4. Pop / Hold / Out 时长与关键帧是否一致（尤其 Pop 的弹性缩放与 5px 上飘）  
5. Canvas 与 DOM 是否同源规格，无单端漂移  
6. 高频场景是否走 Canvas，避免 DOM 尖峰  

---

## 10. 风格摘要（提示词）

> 移动端 H5 游戏内胶囊飘字：圆角 14px，浅绿半透明底 `rgba(129,199,132,0.78)`，白描边 1.2px、柔和阴影；白字加粗 12px / 行高 1.35，单行。无尾巴、无点击。警告态浅黄底 `rgba(255,224,130,0.82)`。动画：500ms 弹性放大并轻颤上飘 → 600ms 驻留 → 280ms 缩至 0.68 并淡出。高频用 Canvas 同款自绘，低频可用 DOM 浮层。
