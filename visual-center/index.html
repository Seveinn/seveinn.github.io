使用说明

  • 推荐双击 start-visual-center.bat（或 打开可视化中心.bat）启动本地服务。
  • 左侧浏览 Markdown 文档与 HTML 开发工具。
  • 工具默认页内运行；若不兼容可点「在新页打开」。
  • 浏览器开发者工具请按 F12 或 Ctrl+Shift+I。
  • 停止服务：启动窗口按 Ctrl+C，或双击 stop-visual-center.bat。
